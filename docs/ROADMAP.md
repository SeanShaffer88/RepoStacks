# Roadmap

1. **Foundation** (this slice) — core operations + CLI, gated locally.
2. **Network + search/view slice** (done) — live Atom checks, metadata refresh under the
   cache policy, rich search language, saved searches, switchable layouts/themes, bulk import.
3. **Download slice** (done) — engine with Range resume + checksum verification,
   persisted queue, asset rules, standing orders.
4. **Window slice** — Tauri shell over the core, dark ledger design (owner's pick), built
   from the owner's eight screen concepts, adapted to Windows-first v1.
5. **First release** — grouped v0.1.0: Setup.exe + Portable.zip + SHA256SUMS.txt.
