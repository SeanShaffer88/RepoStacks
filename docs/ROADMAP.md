# Roadmap

1. **Foundation** (done) — core operations + CLI, gated locally.
2. **Network + search/view slice** (done) — live Atom checks, metadata refresh under the
   cache policy, rich search language, saved searches, switchable layouts/themes, bulk import.
3. **Download slice** (done) — engine with Range resume + checksum verification,
   persisted queue, asset rules, standing orders.
4. **Window slice** (done) — Tauri shell over the core, dark ledger design (owner's pick),
   screens adapted from the owner's eight concepts to Windows-first v1; Librarian
   scheduler + DPAPI token storage included.
5. **Grouped releases v0.1.0–v0.8.0** (done) — user/org imports, self-suggesting
   asset rules, the ten-improvement slice, graceful feed fallback, single-instance
   guard, and background download worker; each release exactly Setup.exe +
   Portable.zip + SHA256SUMS.txt.
6. **API-usage meter** (done, v0.9.0) — persistent local ledger of counted REST
   calls by purpose; CLI `usage` command and a Librarian-screen meter.
7. **Next** — fresh README screenshots from the current interface (captures come
   from a real run), then further slices as directed.
